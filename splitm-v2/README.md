# SplitM v2 Frontend

This directory contains the SplitM Progressive Web Application built with React 19, Vite 8, TypeScript, Redux Toolkit, and Tailwind CSS v4.

For architecture overview, configuration, testing, and deployment instructions, refer to the [Root README](../README.md).

## Quick Commands
- `npm run dev` — Start Vite development server
- `npm run build` — Typecheck (`tsc -b`) and build production bundle
- `npm run preview` — Preview the production build locally
- `npm run lint` — Run oxlint code quality checks
